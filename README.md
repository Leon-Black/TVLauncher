# TV Launcher

面向 Android TV 的轻量桌面，支持遥控器方向键、应用列表和本地自选壁纸。默认背景为灰色 `#808080`，不内置照片。

## 兼容范围与当前状态

- 最低 Android 10（API 29），横屏、遥控器方向键操作。
- 主要验证设备为 Sony BRAVIA 4K UR2（Android 10）；其他品牌和系统版本尚未完成验证。
- 0.1.0 正式 APK 已通过构建、Lint 和签名检查；用户已在电视安装正式版和测试版，并反馈基础试用无问题；默认桌面接管及整机重启尚未单独确认。详见 [发布验证](docs/release-validation.md)。

## 安装与更新

从项目发布附件下载正式 APK，在电视上使用文件管理器安装；系统如有提示，允许该安装来源安装应用。也可使用 [ADB](docs/DEVELOPMENT.md#安装和设备测试)。

安装后，先从电视现有桌面打开 TV Launcher，验证遥控导航和应用启动。应用包名为 `me.leon.tvlauncher`。

正式版名称为“TV Launcher”，包名 `me.leon.tvlauncher`；新版测试版名称为“TV Launcher 测试版”，包名 `me.leon.tvlauncher.debug`。两版可同时安装，壁纸和设置各自独立；同一时间只能选择其中一个为默认桌面。

相同包名、相同签名的后续版本可覆盖更新。早期测试版曾使用正式包名，与正式签名冲突，首次切换仍需备份并卸载旧测试版。新版独立包名测试版没有这项冲突。卸载或清除数据会删除已保存的壁纸及应用设置。应用关闭了 Android 自动备份，不应依赖系统自动恢复数据。

## 遥控器操作

| 位置 | 操作 | 结果 |
|---|---|---|
| 首页 Dock | 左右键 | 切换应用 |
| 首页 Dock | 下键 | 展开全部应用，定位对应应用 |
| 首页 Dock | 上键 | 进入顶部快捷按钮区域 |
| 应用列表 | 方向键 | 在四列应用中移动 |
| 应用列表 | 首行按上，或按返回 | 收起列表，恢复 Dock 焦点 |
| 应用卡片 | 确认键 | 启动应用 |
| 顶部设置按钮 | 确认键 | 打开系统设置 |
| 顶部壁纸按钮 | 确认键 | 打开壁纸抽屉 |
| 壁纸抽屉 | 左右键、确认键 | 浏览并应用图片 |

应用按名称排序、同包名去重，读取电视应用入口和声明支持电视的 Home 入口。仅有普通手机启动入口的应用可能不会显示。

## 壁纸位置和权限

把图片放入电视共享存储的 **`Pictures/Wallpaper/`** 目录，支持该目录下的子文件夹。常见完整路径为：

```text
/sdcard/Pictures/Wallpaper/
```

目录名按 `Wallpaper` 拼写。其他目录的图片不会出现在壁纸抽屉中，当前不提供目录选择或壁纸轮播。图片须能被电视系统解码。

第一次打开壁纸抽屉时会申请图片读取权限：

| 系统版本 | 读取方式 |
|---|---|
| Android 10 | 取得存储读取权限后直接扫描目录，包括尚未被媒体库索引的图片 |
| Android 11–12 | 取得存储读取权限后从系统媒体库筛选固定目录 |
| Android 13 | 取得图片读取权限后从系统媒体库筛选固定目录 |
| Android 14 及以上 | 支持全部或部分图片授权；部分授权时只显示固定目录内获准的图片 |

拒绝授权时无法浏览目录图片。可在电视的应用权限设置中重新授权；具体入口取决于系统。Android 11 及以上如果图片已放入正确目录但仍不显示，请检查授权和系统媒体库是否已索引该图片。

确认选择后，图片会复制到应用私有目录。原共享图片删除后，当前壁纸仍可保留；卸载或清除数据会删除私有副本。没有保存的壁纸，或保存文件无法读取时，背景使用默认灰色。图片按比例裁切铺满屏幕。

## 设为默认桌面与恢复

先验证作为普通应用运行的行为，再尝试设为默认桌面。系统若提供“默认应用 / 主屏幕应用 / Home 应用”设置，可选择 TV Launcher；恢复时在同一入口选择原桌面。

不同电视厂商可能隐藏或限制桌面选择，当前不提供通用的强制替换步骤。请保留原桌面；本项目的安装不会自动停用原桌面或修改默认 Home 设置。正式包的 Home 键接管和重启行为尚未完成验收。

## 数据与网络

应用读取本机应用入口、名称和图标，并在用户授权后读取指定目录的图片。用户选定的壁纸保存在本机应用私有目录。当前清单没有声明网络权限，没有接入账号、广告或分析服务；从桌面启动的其他应用遵循各自的数据规则。
